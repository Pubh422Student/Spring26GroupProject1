## Project Overview
This project performs an exploratory univariate analysis of health indicator data from the 2020 US National Cancer Institute (NCI) Health Information National Trends Survey (HINTS). The analysis explores participant demographics, lifestyle health behaviors (alcohol consumption, physical activity, smoking), and healthcare quality perception.
